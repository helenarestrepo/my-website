# Images to add

Drop your photos into this `images/` folder using **exactly** these file names (all lowercase, `.jpg`).
The site picks them up automatically, with no code changes needed. Until a file exists, the site shows a striped placeholder labeled with the file name it's waiting for.

**Tips**
- Export as **JPG, quality ~80%**. Try to keep each file **under 400 KB** so the site loads fast on phones (free tool: [squoosh.app](https://squoosh.app)).
- Bigger is fine if the **shape (aspect ratio)** matches; the site crops to fill the frame.
- Only use client work you're allowed to share publicly. Check with GlueIQ / the client if unsure.

### Want to change a caption or alt text?
Open `index.html`, search for the file name (e.g. `monarch-cover.jpg`), and edit the `alt="..."` text right next to it. Alt text describes the image for screen-reader users, so keep it short and specific.
